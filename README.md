# 🐍 15 Days Python Revision Challenge

> Strengthening Python fundamentals before starting Data Structures & Algorithms (DSA).

## 📖 About This Repository

This repository documents my **15-day Python revision journey**.

Instead of simply watching tutorials, I am revisiting every important Python concept by writing code, solving practice problems, and building strong programming fundamentals.

My goal is to develop a solid understanding of Python before moving on to Data Structures & Algorithms (DSA).

---

## 🎯 Objectives

- Revise Python from basic to advanced concepts
- Build strong programming logic
- Practice coding every day
- Solve real programming problems
- Improve code quality and consistency
- Prepare for DSA and LeetCode
- Maintain a public learning journey on GitHub
